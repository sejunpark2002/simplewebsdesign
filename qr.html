Getting a code that actually scans

01

Print it big enough

Roughly 2cm across for a table card, and 10× that for a poster read from across the room. Bigger beats clever every time.

02

Keep the quiet zone

The white margin around the code is part of the code. We add it for you — don't crop it off in your layout.

03

Use high correction on print

Level H keeps the code readable after a scuff, a fold or a bit of ink spread. Level M is plenty for screens.

04

Shorter links, smaller grid

A short URL means fewer modules, which means a chunkier, more forgiving code. Point it at a tidy page on your own domain.
